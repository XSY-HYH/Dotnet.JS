1.npm构建在特殊路径下会失败
2.一部分pip安装的模块没有环境变量，记得使用python -m模块名
3.run是一个特殊命令，有很多非path下的工具可以尝试用run启动
4.run assemblyAnalyzer就是一个工具，用于分析程序集：
run assemblyAnalyzer
AssemblyAnalyzer - .NET程序集分析工具
用法:
  AssemblyAnalyzer <程序集路径>                - 显示摘要信息
  AssemblyAnalyzer <程序集路径> -t <类型名>   - 显示类型详细信息
  AssemblyAnalyzer <程序集路径> -d <类型名>   - 反编译指定类型（显示IL代码）
  AssemblyAnalyzer <程序集路径> -dep          - 显示依赖
  AssemblyAnalyzer <程序集路径> -o <文件>     - 导出到文件

注意: -d 参数会显示方法的IL代码（字节码）
